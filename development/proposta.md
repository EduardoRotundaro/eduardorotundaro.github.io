# Proposta do projeto

Este projeto funcionará como uma documentação viva, com guias rápidos, resumos e pontos chaves de diversos assuntos.
O nome 'handbook' ilustra bem a proposta, funcionar como um "manual de bolso".
A idéia é ir enriquecendo esse reposítorio a medida que evoluo com estudos e pesquisas.


## Evolução do conteúdo

Vou evoluir esse projeto adicionando o conteúdo através de arquivos markdowns.


## Resultado final

O objetivo final é ter a documentação online, para ser de fácil acesso.
Pensei em 2 caminhos:

1) Repositório de markdowns no Github
- Serão adicionados em uma pasta arquivos simples em markdown, sem preocupação com a UI final;
- Haverá uma skill (ou algo melhor) que lê esses docs e faz: formatação e organização, melhorias visuais e revisão de texto;
- O resultado fica navegável no Github;
- 1 problema: a UI fica limitada aos recursos do Markdown;

2) App simples 
- Tenho preferência nesta opção;
- Uma aplicação simples, estática;
- Terá um menu com os assuntos;
- Uma página por assunto;
- Serão adicionados em uma pasta arquivos simples em markdown;
- Haverá uma skill (ou algo melhor) que lê esses docs e faz: a criação da página e a revisão de texto;
- 1 vantagem: o CSS vai permitir criar qualquer UI;

> Para esta opção:
- Faça a sugestão de como seria feita a aplicação? (framework ou vanilla - html e css puro)
- Me indique a melhor forma de publicar (usar o github pages por exemplo?)
